# Modern Web Calculator

A responsive browser-based calculator built with **HTML5, CSS3, and vanilla JavaScript**. The project focuses on a clean interface, reliable arithmetic input, keyboard interaction, and a mobile-friendly layout without a framework or build system.

## ✨ Features

- ➕ Addition, subtraction, multiplication, and division
- ⌨️ Keyboard and number-pad input
- 🧮 Expression evaluation with basic error handling
- 🚫 Division-by-zero protection
- 🖥️ Responsive desktop and mobile layout
- 🌙 Modern dark calculator interface
- ⚡ Runs entirely in the browser

## 🧱 Architecture

The application is a static client-side web app:

```text
User input
   ↓
HTML calculator interface
   ↓
JavaScript event handling
   ↓
Expression / arithmetic processing
   ↓
Updated display
```

There is no backend, database, or package installation required.

## 🛠️ Technology Stack

| Technology | Role |
| --- | --- |
| HTML5 | Calculator structure and controls |
| CSS3 | Responsive layout and visual design |
| Vanilla JavaScript | Input handling and calculations |
| Flexbox / Grid | Interface layout |

## 🚀 Run locally

Clone the repository:

```bash
git clone https://github.com/Harsh0675/Calculator.git
cd Calculator
```

Then open `index.html` in a modern browser.

You can also serve the directory with any static HTTP server if preferred.

## ⌨️ Interaction

Use the on-screen calculator buttons or a physical keyboard to enter numbers and operators. Invalid expressions and unsupported operations are handled without requiring a server.
