# Modern Web Calculator

A clean, responsive, and fully functional web-based calculator built with HTML, CSS, and JavaScript.

## 🚀 Features

- **Basic Arithmetic**: Addition, subtraction, multiplication, and division.
- **Modern UI**: Sleek dark mode design with hover and active states.
- **Error Handling**: Safely handles syntax errors and division by zero.
- **Keyboard Support**: Type directly using your number pad or keyboard.
- **Responsive Design**: Adapts smoothly to mobile and desktop screens.

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript (ES6+)

## 💻 How to Run Locally

1. Clone the repository or extract the ZIP.
2. Open `index.html` directly in your favorite web browser.
